AI MIDI Generator API

Generate professional multitrack MIDI arrangements from structured parameters or plain-text descriptions. Built on the same AI engine that powers midi-aigenerator.vercel.app.

Bring Your Own Pollinations Key (BYOP): Every generation request must include your own Pollinations API key in the X-Pollinations-Key header. Your Pollinations account pays for generation. The mgk_ key only authenticates access to this API. There is no monthly generation quota; a short per-key rate limit protects the API infrastructure. The Pollinations key is used for the request only and is not stored by this API.

POST /api/v1/import — Import MIDI

POST/api/v1/importAnalyze MIDI and generate companion tracks

Upload a Standard MIDI File as base64. The API analyzes its tempo and note content, reports a best-effort role for each playable track, and can generate up to four new melodic companion tracks. Original imported tracks are returned as note notation and are never modified.

Required JSON fields: midiBase64 (base64-encoded .mid file, maximum 3 MB). Optional: model (see AI Models), trackTypes (up to four of bassline, chord, melody, arpeggio, lead, plucks, strings, keys, pad-textures, guitar, brass), bpm, model.

curl -X POST https://midi-aigenerator.vercel.app/api/v1/import \
  -H "Authorization: Bearer mgk_YOUR_KEY" \
  -H "X-Pollinations-Key: YOUR_POLLINATIONS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"midiBase64":"BASE64_ENCODED_MIDI","trackTypes":["bassline","pad-textures"],"model":"google/gemini-4-argon"}'

Response: analysis contains BPM and track classifications; importedTracks contains the original track notation; generated contains only the requested new companion tracks.

POST /api/v1/tracks/edit — Edit selected tracks

POST/api/v1/tracks/editDeterministic and AI-assisted editing

Submit a composition using pitch:beat:duration:velocity|... notation and select 1–6 existing tracks. Unselected tracks are immutable references and are returned unchanged.

Optional top-level model selects the model for AI-assisted edits; it is ignored for deterministic local edits. See AI Models.

Deterministic editType values: transpose_up, transpose_down, quantize, velocity_up, velocity_down, velocity_normalize. These do not call AI. Other edit types, including custom, use Pollinations and require instructions.

curl -X POST https://midi-aigenerator.vercel.app/api/v1/tracks/edit \
  -H "Authorization: Bearer mgk_YOUR_KEY" \
  -H "X-Pollinations-Key: YOUR_POLLINATIONS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "composition":{"title":"Night Drive","tracks":{"bassline":"36:0:1:8|36:2:1:7","melody":"60:0:0.5:7|64:1:0.5:8"}},
    "targetTracks":["melody"],
    "editType":"custom",
    "model":"openai/gpt-6.1-terra",
    "instructions":"Create a more memorable motif while preserving the key and groove.",
    "intensity":0.5,
    "bpm":124,
    "key":"F",
    "scale":"minor"
  }'

Response: composition contains the edited arrangement; edit reports target tracks, unchanged tracks, and whether AI was used. Supported notation uses MIDI pitches 0–127, non-negative beat positions, positive durations, and velocities 1–9.

Text Prompt Mode NEW

Send only a plain-text prompt — the API extracts BPM, key, scale, style, mood, and track types automatically from the description. Explicit fields in promptParams override extracted ones.

Track Types

Each track type produces a distinct musical role. Mix up to 6 per request.

trackTypeMIDI RangeCharacter
bassline36–52Monophonic. Root notes and fifths. The rhythmic low-end anchor.
chord48–722–4 note voicings. Harmonic comping, not every beat.
melody60–84Monophonic. Clear motifs with mandatory rests.
arpeggio55–7916th/8th note chord-tone patterns. Rhythmic pulsing.
lead62–88Monophonic. Legato soaring phrases with high velocity.
plucks60–84Staccato. Short attack, sparse off-beat accents.
strings48–79Polyphonic. Long sustained notes. Background harmonic texture.
keys48–76Rhythmic comping. Syncopated jazz/pop voicings.
pad-textures45–72Ultra-long notes (4+ beats). Ambient atmospheric wash.
brass42–75Punchy stabs. Syncopated accents with high velocity.
percs60–72Non-tonal. Style-aware rhythmic fills. Velocity varies 1–9.
guitar40–76Strummed or picked patterns. Organic rhythm feel.

Percussion patterns adapt to genre automatically — e.g. techno gets driving industrial 16ths, jazz gets brush swing with ghost notes, reggae gets one-drop rim clicks.

Note format

Each track value is a |-separated list of notes: pitch:beat:duration:velocity

FieldTypeDescription
pitchintegerMIDI note number 0–127 (middle C = 60)
beatfloatStart time in beats from 0, multiples of 0.25

velocityinteger1–9 (maps to MIDI 1–127)

StatusCauseWhat to do

Error response shapes

// 401
{ "error": "API key not found" }

Recommended error handling

const res = await fetch('/api/v1/midi', { ... });

if (!res.ok) {
  const err = await res.json();
  switch (res.status) {
    case 429:
      const retryAfter = res.headers.get('Retry-After');
      console.error(`Limit reached. Retry after ${retryAfter}s. Resets: ${err.resetAt}`);
      break;
    case 401: case 404:
      console.error('Invalid API key:', err.error);
      break;
    case 400:
      console.error('Bad params:', err.details?.join(', '));
      break;
    default:
      console.error('Generation error:', err.error);
  }
  return;
}

Examples — Get JSON

const res = await fetch('https://midi-aigenerator.vercel.app/api/v1/midi', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer mgk_YOUR_KEY',
    'X-Pollinations-Key': 'YOUR_POLLINATIONS_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    promptParams: {
      key: 'A', scale: 'minor', bpm: 132, bars: 8, style: 'techno', mood: 'dark',
      trackTypes: ['bassline', 'lead', 'pad-textures', 'percs']
    }
  })
});

// Collect streaming response
const reader  = res.body.getReader();
const decoder = new TextDecoder();
let text = '';
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  text += decoder.decode(value, { stream: true });
}
const midi = JSON.parse(text);
console.log(midi.title, Object.keys(midi.tracks));

Examples — Python

import requests, json

# JSON response
r = requests.post(
  'https://midi-aigenerator.vercel.app/api/v1/midi',
  headers={'Authorization': 'Bearer mgk_YOUR_KEY', 'X-Pollinations-Key': 'YOUR_POLLINATIONS_API_KEY', 'Content-Type': 'application/json'},
  json={'promptParams': {
    'key':'F', 'scale':'major', 'bpm':95, 'style':'jazz', 'bars':4,
    'trackTypes':['bassline','keys','melody']
  }},
  stream=True
)
text = ''.join(c.decode() for c in r.iter_content(chunk_size=None))
midi = json.loads(text)
print(midi['title'], list(midi['tracks'].keys()))

# Save .mid file
r = requests.post(
  'https://midi-aigenerator.vercel.app/api/v1/midi?format=midi',
  headers={'Authorization': 'Bearer mgk_YOUR_KEY', 'X-Pollinations-Key': 'YOUR_POLLINATIONS_API_KEY', 'Content-Type': 'application/json'},
  json={'prompt': 'cinematic strings at 80 BPM in D minor, 8 bars'}
)
with open('track.mid', 'wb') as f:
    f.write(r.content)
print('Saved track.mid')
