Response Format

The response body streams as plain text and resolves to a JSON object:

{
  "title": "Shadowed Groove",
  "desc": "Dark house at 120 BPM in C minor with driving bass and ethereal pads",
  "tracks": {
    "bass": "36:0.0:0.5:8|36:0.5:0.5:6|38:1.0:0.5:7|...",
    "mel":  "60:0.0:1.0:7|62:1.0:0.5:6|...",
    "pad":  "48:0.0:8.0:3|52:0.0:8.0:2|..."
  }
}

Track keys use abbreviated names: bass=bassline, mel=melody, pad=pad-textures, arp=arpeggio, chd=chord, lead=lead, plk=plucks, str=strings, keys=keys, brss=brass, perc=percs.

Each track value is a pipe-separated list of notes: pitch:beat:duration:velocity where pitch is a MIDI integer (0–127), beat/duration are floats in beats, and velocity is 1–9.

Error Codes

All errors return JSON with an error field. Handle them explicitly in your code.

StatusCode / CauseWhat to do
400Validation failedCheck details array in response — lists every invalid field
401Missing or malformed keyEnsure header is Authorization: Bearer mgk_xxx
404Key not foundKey may be wrong — re-check or re-register
429Monthly limit reachedCheck resetAt field for reset date. Response also includes remaining: 0
502Upstream AI errorRetry after a few seconds — transient Pollinations issue
504Generation timeoutRequest exceeded 25s — retry, or reduce bars or trackTypes count

Error response shape

// 400 example
{ "error": "Validation failed", "details": ["bpm must be a number between 40 and 220", "scale must be one of: major, minor, ..."] }

// 429 example
{ "error": "Monthly limit reached (50 calls/month). Resets on the 1st of next month.", "remaining": 0, "resetAt": "2025-05-01T00:00:00.000Z" }

// 401 example
{ "error": "API key not found" }

Recommended error handling (JS)

const res = await fetch('https://midi-aigenerator.vercel.app/api/midi', { ... });

if (!res.ok) {
  const err = await res.json();
  if (res.status === 429) {
    console.error(`Limit reached. Resets: ${err.resetAt}`);
  } else if (res.status === 401 || res.status === 404) {
    console.error('Invalid API key');
  } else if (res.status === 400) {
    console.error('Bad params:', err.details.join(', '));
  } else {
    console.error('Generation error:', err.error);
  }
  return;
}
// ... read response

Examples

Get JSON (streaming)

const res = await fetch('https://midi-aigenerator.vercel.app/api/v1/midi', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer mgk_YOUR_KEY', 'Content-Type': 'application/json' },
  body: JSON.stringify({
    promptParams: {
      key: 'A', scale: 'minor', bpm: 132,
      style: 'techno', mood: 'dark', bars: 8,
      trackTypes: ['bassline', 'lead', 'pad-textures', 'percs']
    }
  })
});

const reader = res.body.getReader();
const decoder = new TextDecoder();
let text = '';
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  text += decoder.decode(value);
}
const midi = JSON.parse(text);
console.log(midi.title, Object.keys(midi.tracks));

Download as .mid file

Add ?format=midi to receive a binary .mid file instead of JSON. The AI generates the MIDI, the server converts it, and you get a file ready to drag into any DAW.

// Browser — triggers download dialog
const res = await fetch('https://midi-aigenerator.vercel.app/api/midi?format=midi', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer mgk_YOUR_KEY', 'Content-Type': 'application/json' },
  body: JSON.stringify({
    promptParams: { key: 'F', scale: 'dorian', bpm: 120, style: 'house', bars: 8,
      trackTypes: ['bassline', 'chord', 'melody', 'pad-textures'] }
  })
});
const blob = await res.blob();
const url  = URL.createObjectURL(blob);
const a    = document.createElement('a');
a.href = url; a.download = 'my-track.mid'; a.click();

Python

import requests, json

# Get JSON
r = requests.post(
  'https://midi-aigenerator.vercel.app/api/midi',
  headers={'Authorization': 'Bearer mgk_YOUR_KEY', 'Content-Type': 'application/json'},
  json={'promptParams': {'key':'F','scale':'major','bpm':95,'style':'jazz','bars':4,
    'trackTypes':['bassline','keys','melody']}},
  stream=True
)
text = ''.join(c.decode() for c in r.iter_content(chunk_size=None))
midi = json.loads(text)
print(midi['title'])

# Save .mid file
r = requests.post(
  'https://midi-aigenerator.vercel.app/api/midi?format=midi',
  headers={'Authorization': 'Bearer mgk_YOUR_KEY', 'Content-Type': 'application/json'},
  json={'promptParams': {'key':'F','scale':'major','bpm':95,'style':'jazz','bars':4,
    'trackTypes':['bassline','keys','melody']}}
)
with open('track.mid', 'wb') as f:
    f.write(r.content)
print('Saved track.mid')
